## Full description (881/4000)

```
Compose Experiments is a small collection of UI experiments built with Compose Multiplatform. The same Kotlin code runs this app on Android and the web version in your browser.

What's inside:
• Book wall: Covers laid out in a tilted diamond lattice, like the shelf in a popular library app.
• Title card: A line of text that zooms in and slides off screen, in the style of a TV title sequence.
• Glowing button: A pill button with an animated green-to-yellow gradient shadow.
• Water tracker: Tap to add water and watch the level rise, with a moving wave drawn using a mesh gradient.

The app has no accounts, ads or tracking. It asks for no permissions and doesn't use the internet.

The source code is on GitHub at github.com/kevindesai777/compose-experiments, and you can try the web version at kevindesai777.github.io/compose-experiments.

I'll add more experiments over time.
```
